# Portfólio Débora Guerra | Data & Marketing Analytics

Portfólio interativo e responsivo de **Débora Guerra**, com projetos em Engenharia de Dados, pipelines analíticos e análise de performance de mídia e Trade Marketing em marketplaces.

---

## 🚀 Tecnologias Utilizadas

- **React 18** & **TypeScript**
- **Tailwind CSS** para estilização moderna e delicada
- **Vite** para desenvolvimento rápido e build otimizado
- **Lucide Icons** para ícones de interface
- Suporte a múltiplos idiomas (**Português** e **Inglês**)

---

## 📦 Como Executar Localmente

### 1. Clonar o repositório
```bash
git clone https://github.com/SEU-USUARIO/portfolio-debora-guerra.git
cd portfolio-debora-guerra
```

### 2. Instalar as dependências
```bash
npm install
```

### 3. Iniciar o servidor de desenvolvimento
```bash
npm run dev
```

Acesse a aplicação no navegador em `http://localhost:3000` (ou na porta indicada no terminal).

### 4. Gerar build de produção
```bash
npm run build
```
Os arquivos otimizados para produção serão gerados na pasta `dist/`.

---

## 🌐 Deploy Rápido

Você pode facilmente hospedar este projeto gratuitamente no **Vercel**, **Netlify** ou **GitHub Pages**:
- **Vercel**: Importe o repositório diretamente pelo painel da Vercel. O framework Vite será detectado automaticamente.
- **Netlify**: Conecte ao GitHub com build command `npm run build` e publish directory `dist`.
