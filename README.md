# Portfólio Débora Guerra

Site estático puro em HTML, CSS (Tailwind) e JavaScript nativo, pronto para publicação no GitHub Pages sem necessidade de compilação ou configuração adicional.

## Como Publicar no GitHub Pages:
1. Extraia o conteúdo deste arquivo zip no seu computador.
2. Copie os arquivos (`index.html`, `404.html`, a pasta `assets`) diretamente para a raiz do seu repositório no GitHub (`https://github.com/deboracguerra/DEBORA_GUERRA`).
3. No GitHub, vá em **Settings** > **Pages**.
4. Em **Branch**, selecione `main` (ou `master`) e `/ (root)`.
5. Clique em **Save**. Em 1 minuto seu site estará online em `https://deboracguerra.github.io/DEBORA_GUERRA/`.
