## 💻 Como Rodar Localmente

### 1. Clonar ou extrair o repositório
```bash
git clone https://github.com/SEU-USUARIO/portfolio-debora-guerra.git
cd portfolio-debora-guerra
```
*(ou simplesmente descompacte o arquivo `.zip` na sua máquina e abra a pasta no terminal ou VS Code)*

### 2. Instalar as dependências
```bash
npm install
```

### 3. Iniciar o servidor de desenvolvimento
```bash
npm run dev
```
Abra o navegador no endereço indicado (geralmente `http://localhost:3000` ou `http://localhost:5173`).

### 4. Gerar os arquivos de produção
```bash
npm run build
```
Os arquivos prontos e minificados serão gerados na pasta `dist/`.

## 🚀 Como Publicar no GitHub e Colocar o Site no Ar

### Opção A: GitHub Pages com Publicação Automática (Recomendado)
Este repositório já inclui a automação do GitHub Actions em `.github/workflows/deploy.yml`.

1. Suba os arquivos para o seu repositório no GitHub (veja as instruções abaixo).
2. No seu repositório no GitHub, clique na aba **Settings** > **Pages** (no menu lateral esquerdo).
3. Na seção **Build and deployment** > **Source**, selecione **GitHub Actions**.
4. Pronto! A cada `git push` na branch `main`, o GitHub criará e publicará seu site automaticamente no endereço:
   `https://SEU-USUARIO.github.io/portfolio-debora-guerra/`

### Opção B: Vercel (1 clique)
1. Acesse [vercel.com](https://vercel.com) e conecte com seu GitHub.
2. Clique em **Add New Project** e selecione este repositório.
3. O Vite será detectado automaticamente. Clique em **Deploy**.

### Opção C: Netlify
1. Acesse [netlify.com](https://netlify.com) e conecte com o GitHub.
2. Selecione o repositório, com Build Command `npm run build` e Publish Directory `dist`.
3. Clique em **Deploy Site**.

## 📤 Como Subir ou Substituir Arquivos no GitHub

### Método 1: Pelo Terminal (Git CLI)
```bash
# 1. Dentro da pasta do projeto descompactado:
git init
git remote add origin https://github.com/SEU-USUARIO/portfolio-debora-guerra.git

# 2. Adicionar todos os arquivos e commitar:
git add .
git commit -m "feat: atualização completa do portfólio de Débora Guerra"

# 3. Enviar para a branch principal (main):
git branch -M main
git push -u origin main --force
```

### Método 2: Pelo GitHub Desktop
1. Abra o **GitHub Desktop**.
2. Abra seu repositório local existente.
3. Copie todos os arquivos desta pasta extraída e cole dentro da pasta do repositório (substituindo os existentes).
4. O GitHub Desktop detectará automaticamente todas as alterações.
5. Digite uma mensagem de commit (ex: *Atualização do portfólio*) e clique em **Commit to main** e depois em **Push origin**.

### Método 3: Diretamente pelo site GitHub.com
1. Abra seu repositório no navegador em `github.com/SEU-USUARIO/portfolio-debora-guerra`.
2. Clique em **Add file** > **Upload files**.
3. Arraste todos os arquivos e pastas da versão descompactada (exceto `node_modules` e `.git`).
4. Clique em **Commit changes**.
